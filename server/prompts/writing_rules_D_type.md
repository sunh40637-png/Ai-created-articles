# 纯文字短合集写作规则 v1.0

> 适用账号：煮酒问人生
> 内容类型：D型·纯文字短合集
> 发布频率：每天1条
> 目标读者：45-70岁中老年用户，以中老年女性为主

---

## 一、内容定位

这是账号每日必发的高频内容，不是长篇道理文，而是**把4-6个独立的人生感悟段落拼在一起**，直接说道理，没有故事，没有古文，没有标题，没有图片。

读者在消息列表里看到前两行就被击中，点"展开"看完，然后转发。

核心体验：**短、直接、说中了、想转发。**

---

## 二、整体结构

```
第1段（100-200字）
第2段（100-200字）
第3段（100-200字）
第4段（100-200字）
[可选第5段]
[可选第6段]
固定结尾语
```

- 每段独立成立，不依赖上下文
- 段落之间不需要过渡，直接换行
- 每段开头用数字标注：1、2、3……
- 总字数：500-1000字

## 三、每段写作规范

### 3.1 段落开头

每段第一句是**核心观点句**，要强、要直接、要有冲击感。

常见开头方式：

```
直接说结论：
"人活着，拼的就是一份心情。"
"没弄清前因后果就劝你宽容的人，其实和伤害你的人没两样。"

用场景切入：
"有人对你不好，从来不是你的问题，而是他本身的格局不够。"

用对比切入：
"站得高看到的都是风景，站得低满眼都是琐事。"

用反常识切入：
"真心盼你好的，只有父母；怕你过得比他好的，大多是亲戚。"
```

### 3.2 段落展开

开头一句之后，展开2-4句，方式有三种：

**方式一：举具体例子**
```
"你发朋友圈说买了房，点赞祝福的，大概只有父母、中介和装修公司；
可要是房子出了问题，倒有一群人来关心，问清你有多惨，就心满意足地走了。"
```

**方式二：排比递进**
```
"不想做的事能做好，是能力；
咽不下的气能咽下，是胸怀；
快骂出口的话能忍住，是本事；
看不顺的人能看顺，是修为。"
```

**方式三：直接说透**
```
"信你的人不用解释，不信你的人，说再多也没用。
世间事本就有人评说，不必太在意。"
```

### 3.3 段落结尾

每段最后一句是**收束句**，把道理点透，让读者有"对，就是这个"的感觉。

常见结尾方式：
```
"记住，情绪解决不了任何问题，世上本无烦心事，都是人自寻烦恼。"
"高调易惹是非，沉稳才能走得长远，做好自己的事，才是根本。"
"有些心事只能自己消化，有些无奈只能默默承受。"
```

## 四、语言风格要求

### 4.1 语气

- 直接、有力、不拖泥带水
- 像一个走过半辈子的长者在说话，不是在讲课
- 有时候有点"狠"，说出别人不敢说的话
- 不温吞，不废话，不绕弯子

### 4.2 句式

- 多用短句，一句话一个意思
- 多用排比："不是A，是B"、"A是能力，B是胸怀，C是本事"
- 多用对比："真心对你好的……；想害你的……"
- 多用否定句制造反差："不必……""别……""没必要……"

### 4.3 节奏

- 快、密、有力
- 不铺垫，直接进入核心
- 每句话都要有信息量，没有废话

### 4.4 禁止事项

- 禁止古文引用（这种内容不需要古文）
- 禁止长篇故事（最多一两句举例）
- 禁止空洞鸡汤（"相信自己""努力奋斗"这类无意义的话）
- 禁止AI腔（"综上所述""不得不说""值得注意的是"）
- 禁止破折号（——）
- 禁止说教感太强（道理藏在话里，不是直接命令读者）

## 五、主题方向

每条内容围绕以下主题之一展开，段落之间可以是同一主题，也可以是不同主题拼在一起：

**人际关系类：**
- 看透人性、识别真假朋友
- 不必讨好所有人
- 沉默是最好的回应
- 远离消耗你的人

**心态修养类：**
- 情绪管理，不生气
- 看淡得失，放下执念
- 低调做人，不炫耀
- 格局决定眼界

**家庭婚姻类：**
- 夫妻相处之道
- 父母子女关系
- 家庭规矩和边界

**人生哲理类：**
- 苦难是转运的铺垫
- 健康是最大的财富
- 活好当下，不纠结过去

**示例一：**

1、做人一定要低调，向别人炫耀就是你灾难的开始。买了新车不用到处说，换了新房也不必逢人就提，感情合得来就悄悄珍惜，赚了钱更要守好分寸。哪怕是亲近的人，也得保持沉稳，你猜不透那些笑着道贺的人，心里是不是藏着嫉妒，嘴上说着恭喜，暗地里说不定正打你的主意。

2、有句话让人豁然开朗：没必要让所有人都懂你，也不用总跟人解释自己是什么样的人。这根本没意义，人们只愿意相信自己想看到的样子。所以越来越不爱辩解，只要不碰底线，就算有人背后说闲话，也不会浪费时间反驳。信你的人不用解释，不信你的人，说再多也没用，世间事本就有人评说，不必太在意。

3、真心盼你好的，只有父母；怕你过得比他好的，大多是亲戚；盼你倒霉的，常常是同事。劝你大度的，多半没安好心；教你赚钱的，多半是想赚你的钱。别高估任何一段关系，你发朋友圈说买了房，点赞祝福的，大概只有父母、中介和装修公司；可要是房子出了问题，倒有一群人来关心，问清你有多惨，就心满意足地走了。

## 八、生成任务指令

AI生成一条D型纯文字内容时，按以下步骤执行：

**第一步：选主题**
从五大主题方向中选1-2个，今天写人际关系，明天写心态修养，保持每天主题有变化，不要连续写同一主题。

**第二步：写4-6段**
每段独立，开头一句核心观点，中间展开，结尾点透。段落之间可以主题不同，但语气风格要统一。

**第三步：检查**
- 每段开头是否够强、够直接
- 有没有废话、空话、鸡汤
- 有没有AI腔词汇
- 有没有破折号
- 结尾语是否加上

**输出格式：**
```
1、[第一段内容]

2、[第二段内容]

3、[第三段内容]

4、[第四段内容]

[认同/同意]请点亮文末"爱心"，转发分享，弘扬中华传统文化！
```
