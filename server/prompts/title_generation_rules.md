# 标题生成规则 v1.0

> 适用账号：煮酒问人生
> 用途：AI学习后根据文章内容生成高质量标题
> 目标读者：45-70岁中老年用户，以中老年女性为主

---

## 一、核心原则

标题的唯一目标是让读者看到标题的第一反应是：

**"这说的就是我，我要点进去看。"**

不是让读者觉得"这个有道理"，不是让读者觉得"这个有用"，而是让读者感到被看见、被说中、被理解。

---

## 二、读者心理分析

中老年读者点击文章的动机只有两种：

**第一种：共鸣驱动**
标题说出了他们正在经历或曾经经历的处境，读者感到"这就是写给我的"。

**第二种：好奇驱动**
标题说了一个反常识的结论，或者留了一个悬念，读者想知道为什么、怎么回事。

好标题至少触发其中一种，最好两种都有。

---

## 三、标题基本要求

- 字数：30-50字之间
- 语气：口语化，像一个人在说话，不像标题党，不像广告
- 禁止：夸张词（震惊、绝对、最强）、疑问句结尾、感叹号结尾
- 禁止：AI腔（探讨、维度、层面、赋能、解析）
- 禁止：纯鸡汤（活得通透才是人生赢家）
- 数字：如果文章是清单结构，标题里带数字效果更好，数字放在句中而不是句首

---

## 四、九种标题公式

### 公式一：转折反常识式

**结构：** 前半句说普遍认知，后半句颠覆它

**适用场景：** 文章有反常识观点，道理和读者预期不一样

**模板：**
```
不是[普遍认知]，而是[真相]
[看似负面的事]，未必是[普遍判断]
[看似正面的行为]，往往[出人意料的结果]
```

**示例：**
- 手机日渐安静，无人打扰，未必是坏事
- 越孝顺的子女，父母往往过得越差
- 你越强硬，别人反而越尊重你

---

### 公式二：处境精准锚定式

**结构：** 精准描述一个具体处境，让那个处境里的人立刻感到被看见

**适用场景：** 文章针对特定人生阶段或家庭处境

**模板：**
```
哪怕你再[正面行为]，也千万不要[具体禁忌]
[具体处境]的[人群]，要想明白[X件事]
[年龄/阶段]之后，[反常识感悟]
```

**示例：**
- 哪怕你再孝顺，也千万不要为年过七十五的父母做这几件事
- 男人先走一步，剩下的女人，要想明白这三件事
- 过了五十岁，这几种朋友要慢慢断掉

---

### 公式三：结论前置式

**结构：** 直接把反常识的结论说出来，让读者想进去看为什么

**适用场景：** 文章有一个核心结论，结论本身就有吸引力

**模板：**
```
[反常识结论]
你越[行为]，别人反而越[结果]
决定[重要事情]的，不是[普遍认知]，而是[真相]
```

**示例：**
- 你越强硬，别人反而越尊重你
- 决定寿命长短的，不是运动，不是睡眠，而是情绪
- 家不是靠爱撑的，是靠这3件事撑的

---

### 公式四：现象解读式

**结构：** 描述一个日常现象，给出出人意料的深层解释

**适用场景：** 文章从一个生活现象切入，解释背后的道理

**模板：**
```
[日常现象]，不是[普遍解释]，而是[深层原因]
[日常现象]，是[内心/生活]在说话
家里[某种状态]，不是[表面原因]，是这[X]件事出了问题
```

**示例：**
- 一个人总反复确认门锁、水电，不是强迫症，而是内心在说话
- 家里越来越冷，两口子越来越疏远，不是感情淡了，是这3件事没守住
- 手机安静了，饭局没了，不是人缘变差，是生活终于开始回归本真

---

### 公式五：人生感悟式

**结构：** 用一句有分量的判断，道出普遍的人生真相

**适用场景：** 文章是情感共鸣类，道理深刻但不刺激

**模板：**
```
[人群]与[人群]，本就是[深刻判断]
[重要的事]，往往[出人意料的规律]
别等到[后果]，才[醒悟]
```

**示例：**
- 父母与孩子，本就是一场渐行渐远的旅程
- 别等到失去时才猛然醒悟，原来自己这辈子，把日子过反了
- 能让家走得远的，从来不是钱多钱少，而是这3件事

---

### 公式六：警示提醒式

**结构：** 用警示语触发读者的防御本能

**适用场景：** 文章有强烈的劝诫意味，提醒读者避开坑

**模板：**
```
[熟悉场景]，[具体行为]千万别做，[后果]
这[X]件事守不住，[严重后果]
再[处境]，也不要[具体行为]
```

**示例：**
- 熟人面前，这四句话千万别说，说多了后悔都来不及
- 这3件事守不住，再好的感情也迟早出事
- 再孝顺，也不要替父母做这几个决定

---

### 公式七：故事开头式

**结构：** 用故事的某个细节开头，制造悬念，让读者想知道后续

**适用场景：** 文章开篇有强烈的场景描述或故事细节

**模板：**
```
[具体人物][做了一件事]，[令人意外的结果]
[时间节点]，[人物][行为]，[悬念结果]
[场景描述]，让所有人沉默了
```

**示例：**
- 她伺候了丈夫二十年，开庭那天说了一句话，让所有人沉默
- 深夜路过一户人家，灯还亮着，这样的家全国不知道有多少
- 那年他把通知书锁进抽屉，这一锁就是四十年

---

### 公式八：处境共情式

**结构：** 精准描述一个人生阶段，让处于该阶段的读者强烈共鸣

**适用场景：** 文章针对特定人生阶段的情感处境

**模板：**
```
[退休后/老伴走后/孩子成家后]，才明白[道理]
[具体处境]的人，心里都藏着[情绪]
日子越过越[状态]的[人群]，往往都栽在这[X]件事上
```

**示例：**
- 孩子成家后，很多父母才明白，最深的孤独不是没人陪
- 日子越过越冷、心越离越远的夫妻，往往都栽在这3件事上
- 老伴走后，很多人才懂得，那个最烦的人，其实最爱自己

---

### 公式九：身份认同式（差异化重点）

**结构：** 精准点出目标读者的身份标签，制造"这是写给我的"感觉

**适用场景：** 所有文章均可使用，是最重要的差异化公式

**模板：**
```
[精准身份词]，[反常识结论或处境描述]
嫁给[具体类型]男人的女人，[共鸣结论]
守了[时间/角色]的[人群]，才明白[道理]
成了[身份]的人，[警示或感悟]
```

**常用身份关键词：**

人生阶段词：
```
退休后、人到中年、年过五十、年过六十
孩子成家后、老伴走后、儿女不在身边、空巢之后
```

关系身份词：
```
做父母的、当婆婆的、嫁了人的女人
守了一辈子家的女人、嫁给老实人的女人
成了家的人、有儿有女的人
```

**示例：**
- 守了一辈子家的女人，到最后往往输给了这件事
- 成了家的人，这3件事不守住，家迟早散
- 嫁给老实人的女人，中年以后才明白这是什么感觉

## 五、禁用标题类型

| 类型 | 示例 | 原因 |
|------|------|------|
| 数字开头 | 3个方法让你婚姻幸福 | 像营销号，没有情感共鸣 |
| 疑问句结尾 | 你知道吗？ | 廉价，读者会反感 |
| 感叹号结尾 | 太扎心了！ | 夸张，失去信任感 |
| 夸张词 | 震惊、绝对、最强、100% | 标题党，读者不信任 |
| 纯鸡汤 | 活得通透才是人生赢家 | 无具体信息，没有点击动力 |
| AI腔 | 探讨中年人处世之道的三个维度 | 不像人说话，读者不亲切 |
| 空洞泛指 | 关于父母，我想说几句 | 没有具体信息，无点击动力 |

---

## 六、标题生成任务指令

当需要为一篇文章生成标题时，按以下步骤执行：

**第一步：分析文章**
- 文章类型（A型道理文/B型清单文/C型热点文）
- 核心主题是什么
- 目标读者是哪类人（年龄、身份、处境）
- 文章最有力的一个点（最反常识的结论/最有共鸣的场景/最强的警示）

**第二步：生成5个候选标题**
- 覆盖至少3种不同公式
- 必须有1个身份认同式（公式九）
- 必须有1个故事开头式或转折反常识式
- 每个标题30-50字

**第三步：输出格式**

```
标题①：[标题内容]
公式：[使用的公式名称]
点击动机：[共鸣/好奇/警示/身份认同]

标题②：...（以此类推，共5个）
```

## 七、参考案例（对标账号真实标题）

```
父母与孩子，本就是一场渐行渐远的旅程
接纳失去，是一个人转运的开始
一个人在家里总是烦躁、内耗，不是性格的错，而是这个家出现了三件事
不爱打扮、不爱说话、不爱凑热闹的女人，往往活得最通透
熟人面前，这四句话千万别说，说多了，后悔都来不及
手机安静了，饭局没了，不是人缘变差，是生活终于开始回归本真
男人先走一步，剩下的女人，要想明白这三件事
贵人帮过你之后，慢慢就疏远了，并非人家冷漠
再有人借钱，学会这三句话，既能守住本分，又能保住情分
你越强硬，别人反而越尊重你
决定寿命长短的，不是运动，不是睡眠，而是情绪
睡得怎么样，日子就过得怎么样
```

**这些标题的共同特征：**
- 口语化，像一个人在说话
- 有具体的处境描述，不泛泛而谈
- 结论直接或悬念感强
- 读完让人觉得"说的就是我"
