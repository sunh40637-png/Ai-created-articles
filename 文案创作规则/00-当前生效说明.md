# 当前生效说明

## 当前实际生效规则

当前系统不是整套都走同一版规则，而是混合生效：

- `A型`：使用原版规则
- `B型`：使用最新版规则
- `C型`：使用原版规则

## 为什么这样配置

- `B型`：保留本轮优化后的最新版规则
- `A型 / C型`：回退到原版稳定规则

## 当前规则来源

代码中的实际规则来源：

- [server/contentRuleProfiles.js](/Users/awehome/Documents/文章内容自动化创作系统/server/contentRuleProfiles.js)

运行时选择逻辑：

- `B型 -> 规则B`
- `A型 / C型 -> 规则A`

- A/B 测试能力仍然保留
- 如果后续要继续试验，可继续显式指定 `规则A` 或 `规则B`
