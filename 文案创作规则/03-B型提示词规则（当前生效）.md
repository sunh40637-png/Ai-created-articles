# B型提示词规则（当前生效）

当前状态：

- `B型` 使用最新版规则

## 类型执行重点

- 标题必须包含明确数字
- 整篇必须是清单式结构
- 开篇先用生活场景切入
- 再自然引出今天要聊的 `3 件事 / 3 句话 / 3 个方法`
- 正文固定写三点
- 每一点都要有：
  - 古文或俗语
  - 故事
  - 可操作的道理收尾
- 三个段落的开头方式不能完全一致
- 至少使用两种不同变体
- 结尾必须使用固定结尾语
- 总字数控制在 `1500 到 1800 字`

## 结构随机性要求

每篇文章三个主体段落中，以下三种合法变体不能全部相同，至少要有两种不同方式：

### 变体 A：古文开段

```text
《菜根谭》有言："......"
这句话的意思是……
```

### 变体 B：故事开段，古文在结尾收束

```text
[直接讲故事]
……
正如《增广贤文》所言："......"
[道理收尾]
```

### 变体 C：俗语 / 老话开段

```text
老话说得好："......"
```

或

```text
民间有句话：……
```

## 古文与事实性要求

- 所有《书名》有言 / 有云都要做真实性核查
- 每一处古文引用要输出三种结论之一：
  - `确定真实`
  - `不确定`
  - `确定存疑`
- 若无法确认真实性，优先改写为：
  - `古语有云`
  - `老话说得好`
- 不允许为了好看硬贴具体书名

## 真实人物使用要求

### 允许

- 引用真实历史人物说过的话
- 引用有明确史料记载的事迹

### 禁止

- 给真实历史人物添加虚构对话
- 添加虚构细节
- 添加错误的家庭成员信息
- 伪造著作或语录

## 当前审核口径

审核报告必须包含：

- 结论
- 判定理由
- 结构检查
- 风格检查
- AI腔词汇检查
- 硬性规则检查
- 古文真实性核查
- 可优化建议
- AI已处理动作

## 当前判定标准

### 直接通过

- 一级校验项全部通过
- 二级问题已自动修正
- 三级问题可接受

### 局部修改

- 古文核查出现 `不确定` 或 `确定存疑`
- 故事要素不齐全
- 三段故事弧线过于相似
- 字数在达标线上下 `10%` 以内
- 真实人物信息存疑但未明确捏造

### 必须重写

- 字数低于要求的 `80%`
- `确定存疑` 的古文超过 `2` 处
- 真实历史人物配了明确错误信息
- 结构不完整
- 出现 AI 腔禁用词
- 出现破折号
- 超出账号赛道
