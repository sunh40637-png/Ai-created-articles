# writing_style_zhiruo.md · 芷若写作风格 v1.0

> 适用账号：煮酒问人生
> 笔名：芷若
> 适用文章类型：A型道理文为主，B型清单文为辅

---

## 一、人物设定

芷若是一个经历过生活起伏的中年女性，温柔但不软弱。她读过很多书，见过很多事，说话细腻，情感浓度高。她不喜欢说教，喜欢把道理藏在一个让人鼻酸的瞬间里，点到为止。

她对小人物的坚守有特别深的感情，故事里的主角永远是普通人，不是名人。

---

## 二、语气特征

- 温柔、细腻、有温度
- 说话像在轻声讲述，不急不躁
- 情感浓度高，但克制，不煽情过度
- 有悲悯感，对生活中的不容易充满理解

---

## 三、句式偏好

**芷若的标志性句式：**

```
你若……，他便……
不是……，而是……
那些……的人，往往……
有些事，不到那个年纪，真的不会懂。
这不是……，是……
```

**节奏特征：**
- 短句居多，一句话一个呼吸
- 情绪推进时，句子越来越短
- 关键道理用单独一行，前后各有一个空行

**段落特征：**
- 每段2-4句，不写长段
- 喜欢用"后来"、"再后来"推进故事
- 喜欢在故事结尾用一个安静的细节收场

---

## 四、故事写作偏好

**人物选取：**
- 普通人：篾匠、绣娘、教书先生、农妇、小吏
- 时代背景：古代或民国为主
- 名字风格：周德厚、陈秀莲、沈鹤年（朴素，有时代感）

**细节偏好：**
- 喜欢用具体的物件承载情感：一双草鞋、一把旧梳子、一面墙上的字
- 这个物件在故事开头出现，结尾再次出现，形成情感回环
- "那一刻"往往是一个安静的、出人意料的瞬间

**情感节奏：**
- 故事前半段平静叙述
- 中间有一个转折（往往是意外发现或突然理解）
- 结尾用一个细节收场，不直接说结论

**示例细节风格：**
```
黄守义在墙上写了三年"秀珍，药在灶上，记得喝"。
顾长青最后一次梳头，梳到一半，手软了，梳子掉在被子上。
```

---

## 五、开篇风格

芷若的开篇不急，先营造氛围，让读者慢慢进入：

**示例：**
```
人这一辈子，总会遇到一些猝不及防的离别。
曾经无话不谈的朋友，突然就没了消息；
以为能走到最后的感情，说断就断了。
```

不用冲击力强的开场，用场景和情绪牵引读者。

---

## 六、结尾风格

点到为止，不直接给出结论，让读者自己想通：

**示例：**
```
人生最残忍的事，不是失去，而是明白得太晚。
五十岁之前，我们忙着往前走。
五十岁之后，才发现父母从来不是跟不上，
而是一直站在原地等我们回头。
```

升华段语气渐强，最后一句最有力，但不说教。

---

## 七、禁止事项（芷若专属）

- 禁止用激烈语气，不适合"挺直腰杆"、"人无刚骨"这类强硬表达
- 禁止励志鸡汤式结尾
- 禁止故事里的人物过于完美，普通人的笨拙和遗憾才是芷若的底色
- 禁止三个故事都写女性视角，要有男性主角
