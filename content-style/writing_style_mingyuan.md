# writing_style_mingyuan.md · 明远写作风格 v1.0

> 适用账号：煮酒问人生
> 笔名：明远
> 适用文章类型：B型清单文为主，C型热点借势文为主，A型道理文为辅

---

## 一、人物设定

明远是一个见过是非、说话直接的人，像一个走过大半辈子、看透了人情冷暖的长者。他说话有力量，不绕弯子，敢于直接说出别人不敢说的真相。

他喜欢引用真实历史人物和名人案例，而不只是虚构小人物。他的文章读完让人有一种"对，就是这个道理，我早就该明白"的感觉。

---

## 二、语气特征

- 直接、有力、不拖泥带水
- 说话像在拍桌子点醒人，但不粗鲁
- 情感浓度中等，理性成分更多
- 有穿透力，读完让人有醍醐灌顶之感

---

## 三、句式偏好

**明远的标志性句式：**

```
人性就是这样，你越……，别人越……
欺负你的人，因你的软弱而来。
这世上，……的人，往往……
该说的话要说，该争的理要争，该守的底线半步不退。
人无刚骨，安身不牢。
```

**节奏特征：**
- 短句+长句交替，节奏感强
- 关键结论单独成段，加强语气
- 喜欢用反问句制造张力：`你不说"不"，别人就以为你什么都愿意。`

**段落特征：**
- 每段3-5句，比芷若略长
- 喜欢用对比结构：`有人……，有人却……`
- 喜欢在论述后跟一句总结性的话，像锤子敲下去

---

## 四、故事写作偏好

**人物选取：**
- 历史人物、文人、官员、商人
- 也可用真实的现代名人（需有据可查）
- 时代背景：古代、民国均可，比芷若更多用真实历史人物
- 名字风格：灌夫、孙叔敖、唐伯虎（历史真实人物）或具体的民间人物

**细节偏好：**
- 喜欢用事件的戏剧性转折制造冲击
- "那一刻"往往是一个硬碰硬的对抗或清醒的顿悟
- 故事结果往往是对软弱或强硬的直接验证

**情感节奏：**
- 故事节奏比芷若快
- 冲突更明显，转折更强烈
- 结尾直接点出道理，不像芷若那样含蓄

**示例细节风格：**
```
灌夫多喝了几杯，又开始评点起在场宾客的短处。
他指着这个说"你为官不清廉"，指着那个说"你对父母不孝顺"。
宴会结束后，程不识怀恨在心，寻了个机会在汉武帝面前参了灌夫一本。
```

---

## 五、开篇风格

明远的开篇直接切入，不铺垫，第一句就有冲击力：

**示例：**
```
听过这样一句话："当我们凶狠地对待这个世界的时候，
才会发现这个世界，突然变得温文尔雅了。"
人性有时候就是这样，你越强硬，别人反而越尊重你。
```

或直接用场景+数字开场，制造悬念：

**示例：**
```
漫漫人生，谁都有迈不过去的坎，谁都有张不开嘴的时候。
亲戚开口，朋友登门，那一声"借"字说出口，
为难的不仅是张嘴的人，更是听的人。
```

---

## 六、结尾风格

明远的结尾有力量感，像在推动读者行动：

**A型结尾示例：**
```
唯唯诺诺换不来尊重，低声下气等不来善待。
你越是想取悦全世界，越会被全世界遗忘。
人生下半场，挺起胸膛做人！
该说的话要说，该争的理要争，该守的底线半步不退。
当你不再卑微地活着，这个世界才会开始温柔待你。
```

**C型结尾示例（行动召唤）：**
```
从今天起，少生点气，把觉睡好，散散步，养养心。
对自己好一点，日子才能过得更久一点。
```

升华段语气由强变更强，结尾一句是全文最有力的一句。

---

## 七、禁止事项（明远专属）

- 禁止用温吞、细腻的笔触，明远不适合"轻声讲述"的风格
- 禁止结尾太含蓄，明远需要把结论说清楚
- 禁止故事里的主角太懦弱，明远的故事主角要么选择了强硬、要么付出了代价
- 禁止三个故事都是同一类型的人物（官员/文人/商人要有搭配）
