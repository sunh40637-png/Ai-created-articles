# writing_rules.md · 写作结构规范 v1.0

> 适用账号：煮酒问人生
> 适用范围：所有文章类型（A型/B型/C型）
> 说明：AI写作时必须完整读取并严格遵守本文档

---

## 一、文章类型说明

本账号生产三种类型文章，每次写作前必须明确当前类型：

| 类型 | 名称 | 核心逻辑 | 适用笔名 |
|------|------|---------|---------|
| A型 | 道理文 | 一个人生道理，用2-3个古代/民国故事论证 | 芷若为主 |
| B型 | 清单文 | 给读者可直接使用的方法或认知，标题含数字 | 芷若/明远均可 |
| C型 | 热点借势文 | 以真实热点事件为入口，转入普世道理 | 明远为主 |

## 二、A型道理文结构规范

### 2.1 整体结构

```
开篇（名言+痛点+引出）
→ 正文循环体 × 2-3次
→ 结尾升华
→ 固定结尾语
```

### 2.2 开篇规范

**第一句：名人名言**
- 格式：`XX曾说："......"` 或 `XX在《XX》中写道："......"`
- 引号内不超过30字
- 可用名人范围：杨绛、林语堂、梁漱溟、蔡元培、庄子、毕淑敏、冰心、刘墉、余秋雨、周国平、王安忆、刘震云、三毛、钱穆、曾国藩、南怀瑾、鲁迅、巴金、冯友兰、丰子恺

**第二段：点痛点**
- 2-4句话，描述普通人都经历过的处境
- 口语化，短句
- 让读者第一句就觉得"说的就是我"

**第三段：引出主题**
- 1-2句话过渡
- 常用句式：`今天我们就来聊聊……` / `其实这背后藏着……`

### 2.3 正文循环体规范（重复2-3次）

每个循环体包含以下五个部分，顺序固定：

**① 小标题**
- 8-10字
- 格式：`XX即是XX，XX更见XX` 或 `XX守住XX，XX方得XX`
- 两个层次，有递进关系
- 加粗显示

**② 开段古文**
- 格式：`《书名》有言/有云："......"`
- 然后1-2句白话解释古文含义

**③ 展开论述**
- 2-3句口语化道理
- 多用排比或对比句式
- 句式示例：`你若……，他便……` / `不是……，而是……` / `越是……，越会……`

**④ 故事**
- 字数：350-400字
- 必须要素：有名有姓、有具体地点、有对话、有细节、有转折、有结果
- 故事结构：背景→事件→转折→结果
- 每个故事的情感弧线不能完全相同

**⑤ 古文收尾**
- 格式：`《书名》有言："......"`
- 然后2句白话点明道理，呼应开段古文

### 2.4 结尾规范

**分割线：** 单独一行 `▽`

**升华段：** 3-5句，语气从平静变为有力，多用排比，不直接说教

**固定结尾语（必须原文使用）：**
```
点亮文末"爱心"，愿[祈愿内容]。转发分享，弘扬中华传统文化！
```

### 2.5 字数要求

- 总字数：1800-2000字
- 开篇：150-200字
- 每个循环体：500-600字（故事占350-400字）
- 结尾：100-150字

## 三、B型清单文结构规范

### 3.1 整体结构

```
开篇（场景切入+痛点+引出数字）
→ 第一点（古文+故事+道理）
→ 第二点（古文+故事+道理）
→ 第三点（古文+故事+道理）
→ 结尾升华
→ 固定结尾语
```

### 3.2 开篇规范

B型开篇可以不用名人名言，直接用场景切入：
- 描述一个读者熟悉的具体场景，口语化，有代入感
- 2-4句话后点出"今天聊X件事/X句话/X个方法"

### 3.3 每个"点"的结构

**① 小标题：** 简洁，一眼知道这点讲什么

**② 古文或俗语：** 格式同A型，也可用俗话谚语代替

**③ 故事：** 250-350字，其余要求同A型

**④ 道理收尾：** 2-3句，有可操作性，读者知道"我能怎么做"

### 3.4 字数要求

- 总字数：1500-1800字
- 开篇：100-150字
- 每个点：400-500字
- 结尾：100-150字

## 四、C型热点借势文结构规范

### 4.1 整体结构

```
开篇（热点事件描述+情感钩子+引出思考）
→ 道理一（古文+故事/案例+论述）
→ 道理二（古文+故事/案例+论述）
→ 道理三（古文+故事/案例+论述）
→ 结尾（行动召唤）
→ 固定结尾语
```

### 4.2 开篇规范

- 用热点事件的具体细节开篇（有人名、有数字、有场景）
- 不评论热点本身，只借热点引发情感共鸣
- 3-5句后转入普世道理

### 4.3 结尾规范

C型结尾不用祈愿句，改用行动召唤：
- 格式：`从今天起，……` / `趁还来得及，……`
- 语气更有力量感

### 4.4 字数要求

- 总字数：1800-2000字

## 五、通用语言规范（所有类型适用）

### 5.1 句式要求

- 每句不超过20字，多用句号断句
- 多用排比句，少用长句
- 段落间有节奏感，有快有慢

### 5.2 古文引用规范

- 格式必须统一：`《书名》有言："......"` 或 `《书名》有云："......"`
- 古文必须真实存在，不能捏造
- 引用后必须用白话解释
- 常用古籍：《菜根谭》《增广贤文》《围炉夜话》《论语》《道德经》《庄子》《孟子》《孝经》《礼记》《诗经》《小窗幽记》《格言联璧》《朱子家训》

### 5.3 故事写作规范

- 人物必须有名有姓（可虚构，名字要符合时代背景）
- 地点要具体（XX省XX城/XX县）
- 细节要有画面感（具体物品、对话、动作）
- 每篇三个故事情感弧线要有差异
- 故事结尾要有"那一刻"——让读者情绪被击中的瞬间

### 5.4 禁止事项（硬性规定）

**禁止符号：**
- 禁止使用破折号（——）
- 禁止使用省略号超过一次

**禁止词汇（AI腔）：**
- 总的来说、综上所述、值得注意的是、不得不说
- 毋庸置疑、显而易见、由此可见、总而言之
- 在某种程度上、不仅如此

**禁止内容：**
- 禁止超出账号赛道（不写娱乐八卦、游戏、科技、财经等）
- 禁止捏造古文
- 禁止三段故事完全相同的情感弧线
- 禁止直接说教，道理要藏在故事里
- 禁止在正文中出现第一人称"我"

## 六、质量自检清单

AI写完后，输出前必须自检：

- [ ] 字数是否达标
- [ ] 是否有破折号
- [ ] 是否有AI腔词汇
- [ ] 古文格式是否统一且真实
- [ ] 每个故事是否有名有姓有地点有对话有转折
- [ ] 三个故事情感弧线是否有差异
- [ ] 结尾是否有▽分割线
- [ ] 固定结尾语是否完整
- [ ] 是否超出账号赛道
